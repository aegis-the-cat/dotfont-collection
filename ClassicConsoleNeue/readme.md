Font converted from [Classic Console Neue](https://webdraft.eu/fonts/classic-console/) TTF font.

This font is size showcase of efficiency of dotfont, compare to TTF and WOFF2 formats.

Font Format | Size | Difference
-|-|-
TrueType Font |  606 КБ | 100%
Web Open Font Format 2 | 169 КБ | 27,88%
**dotfont** | **158 КБ** | **26,13%**

This this example is shows, that dotfont is 74% smaller, than TTF, and 6% smaller, than WOFF2. 

Of course, it’s important to keep in mind that dotfont is mostly a “pixel” font.
